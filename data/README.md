# Data organization

This directory stores the dataset inputs, metadata, and intermediate outputs used by RISE. Dataset-specific files are organized under directories such as `HCP/`, `HCPD/`, and `clinical/`.

The main subdirectories are:

- `data/`: preprocessed fMRI data used as inputs to the RISE workflow.
- `info/`: dataset information, subject lists, split definitions, and related metadata.
- `processed_data/`: time-series, voxelwise metrics, parcel-level features, and other outputs generated by RISE preprocessing and feature extraction.
- `integrated_data/`: integrated Feather tables used as input to neural-network training, testing, and embedding extraction.

The integrated Feather files are large and are not included directly in the GitHub repository. Download the required files from the project data link: [download Feather files](xxx).
