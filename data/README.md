# Data organization

This directory stores the dataset inputs, metadata, and intermediate outputs used by RISE. Dataset-specific files are organized under directories such as `HCP/`, `HCPD/`, and `clinical/`.

The main subdirectories are:

- `data/`: preprocessed fMRI data used as inputs to the RISE workflow.
- `info/`: dataset information, subject lists, split definitions, and related metadata.
- `processed_data/`: time-series, voxelwise metrics, parcel-level features, and other outputs generated by RISE preprocessing and feature extraction.
- `integrated_data/`: integrated Feather tables used as input to neural-network training, testing, and embedding extraction.

The HCP subject-list files use `xxxxxx` as a format placeholder. Replace it with your own authorized subject IDs before running the workflows.

## Data access

Access to HCP and HCP-D data requires application through the respective official data portals and acceptance of the applicable data use terms. 

Original imaging data, demographic information, and phenotypic information are available through the following official resources:

- **HCP Young Adult (HCP-YA):** [1200 Subjects Data Release](https://www.humanconnectome.org/study/hcp-young-adult/document/1200-subjects-data-release). 
- **HCP Development (HCP-D):** [Connectome Coordination Facility at the NIMH Data Archive](https://nda.nih.gov/ccf).
